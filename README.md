Figures for the sample-matching review branch (`sample-matching-pr`).

Per-voxel extinction-gradient mean and variance at equal iteration count: the
DRT reference against sample matching at three record-slot counts. Bunny
cloud, 768x576, uniform white environment, 8 spp, N = 512 adjoint renders
with identical seeds, probes_per_segment 4.

Rows carry the cost in path length. The DRT reference runs with subsampling
off, its quadratic setting, so it is compared against a record slot per
segment like for like.

Variance rather than standard deviation, to match the paper. The PDFs carry
vector text.
